# カタカナ禁止！エンジニア用語あてゲーム

社員旅行などで遊ぶための、チーム対抗・カタカナ禁止ゲームです。エンジニア向けの用語を、外来語・英語・略語を使わずに説明し、次のチームが口頭で回答します。

## 起動方法

- `index.html` をブラウザで開いてください。
- JSONをES Modulesとして読み込むため、ブラウザによっては `file://` 直開きでは動作しません。その場合は、プロジェクト直下で簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

GitHub Pagesでは、リポジトリにこのフォルダの中身を配置して公開できます。

## 初期設定

- チーム数：2チーム（2〜4チーム）
- 巡数：3巡
- 1チームの1ターン：60秒（30/60/90秒）
- チーム名は開始前に変更可能

各チームのターン中、チーム内で説明者を自由に選びます。複数人で説明しても構いません。次にプレイするチームが回答・判定を担当します。

## 判定

- 正解：回答チームに1点
- スキップ：0点、回数制限なし
- 違反：そのお題は失格で0点、減点なし
- 禁止表現：外来語・英語・略語
- 違反の最終判断：判定チームの代表者
- 同点：同率順位

## 操作

- 画面のボタン：正解／スキップ／違反／一時停止
- PCの矢印キー：← 正解、→ スキップ、↓ 違反、↑ 一時停止
- 一時停止画面：再開、ルール表示、閉じる
- ルール表示はEscまたは×で閉じる。背景タップでは閉じない。
- スマートフォンでは矢印キー図を表示しません。

## 保存・データ

- ゲーム状態と履歴はブラウザの `localStorage` に保存します。
- 保存に失敗した場合は警告を表示し、手動再保存と操作時の再試行を行います。
- 保存済みゲームは初期画面から再開できます。
- 結果画面からゲーム記録JSON、履歴画面から履歴JSONをダウンロードできます。
- 保存データが壊れている、または未対応形式の場合は原因を日本語で表示し、確認なしに削除しません。

## お題データ

`data/prompts.json` に独自のお題を収録しています。現在は76件です。各お題は `id`、`term`、`description`、`category` を持ちます。`description` は説明者向けの参考情報で、ゲーム画面には表示しません。
