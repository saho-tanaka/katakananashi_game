# カタカナ禁止！エンジニア用語あてゲーム 🎮

エンジニア用語を **カタカナ語・英語・略語を使わずに説明する**、チーム対抗のブラウザゲームです。社員旅行や社内交流会、勉強会などで遊べます。

**▶ [ゲームをプレイする](https://saho-tanaka.github.io/katakananashi_game/)**

## ゲームの概要

- **2〜4チーム**で対戦
- **1〜5巡**、各チームの持ち時間は **30・60・90秒**から設定
- **150問**のお題を収録（初心者105問・中級者30問・上級者15問）
- 出題順はランダム。全お題を使い切ったら再シャッフルして出題を継続
- 正解数に応じて順位を決定。同点は同率順位
- ゲーム終了後は各問題の**用語解説**を確認可能。過去のゲーム履歴からも閲覧可能

## 遊び方

1. チーム数・巡数・制限時間・チーム名を設定し、ゲームを開始します。
2. ターン中のチームが画面のお題を見て、**カタカナ語・英語・略語を使わずに**言葉で説明します。
3. **次のチーム**が回答と判定を担当します。説明担当チーム内では説明者を交代・協力しても構いません。
4. 判定後は次のお題へ進みます。制限時間が終了したら、最後のお題を判定し、確認ボタンで次のチームへ進みます。
5. 全チームが1回ずつプレイすると1巡です。設定した巡数が終わると結果画面に進みます。

### 判定と得点

| 判定 | 得点・処理 |
| --- | --- |
| 正解 | **説明担当チームに1点**。次のお題へ |
| スキップ | 0点。回数制限・減点なし |
| 違反 | 0点。そのお題は失格。減点なし |

禁止表現に該当するか迷った場合は、判定チームで相談し、代表者が最終判断します。

### 操作方法

| 操作 | 画面のボタン | PCのキー |
| --- | --- | --- |
| 正解 | 正解 | `←` |
| スキップ | スキップ | `→` |
| 違反 | 違反 | `↓` |
| 一時停止 | 一時停止 | `↑` |

一時停止中はお題が隠れ、残り時間から再開できます。一時停止メニューからルール確認や**ゲームの途中終了（トップページに戻る）**もできます。途中終了には確認画面を挟みます。

## 結果・履歴

- **結果画面**：チーム別順位・得点・正解数などを表示します。
- **問題の解説**：結果画面で各問題を開くと、用語の説明と判定結果を確認できます。
- **ゲーム履歴**：過去の対戦結果と、出題された問題・解説を確認できます。
- **JSON出力**：ゲーム記録と履歴をJSONファイルとして保存できます。

## お題データ

お題は [`data/prompts.json`](data/prompts.json) で管理しています。

| 難易度 | 問題数 | 割合 |
| --- | ---: | ---: |
| 初心者 (`beginner`) | 105 | 70% |
| 中級者 (`intermediate`) | 30 | 20% |
| 上級者 (`advanced`) | 15 | 10% |
| **合計** | **150** | **100%** |

各お題は `id`・`term`・`description`・`category`・`difficulty` を持ちます。解説はプレイ中には表示せず、ゲーム終了後の振り返りで確認できます。難易度別の出題比率はデータ全体の構成であり、各ターンで一定の比率になるわけではありません。

## ローカルで起動する

このゲームは **HTML・CSS・JavaScript（ES Modules）** で構成された静的サイトです。バックエンドやデータベースの構築は不要です。

```bash
# リポジトリを取得
 git clone https://github.com/saho-tanaka/katakananashi_game.git
 cd katakananashi_game

# ローカルサーバーを起動
 python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開いてください。`file://` からの直接起動は、ブラウザのモジュール読み込み制限により動作しない場合があります。

## データ保存と注意事項

- ゲーム状態・履歴は、利用端末のブラウザの **`localStorage`** に保存されます。別端末や別ブラウザには同期されません。
- ブラウザの保存データを消去すると履歴が失われる場合があります。必要に応じてJSONで保存してください。
- 途中終了を確定すると、進行中の得点・判定記録は破棄されます。完了済みのゲーム履歴は残ります。
- ゲームはGitHub Pagesで公開しています。インターネット接続が必要です。
